## About This Repository

This repository documents the most technical and project-oriented work I developed
during the **IBM Data Analyst Professional Certificate**, with a particular focus on
Courses 6 through 10.

It covers the complete analytical workflow:

**Data Acquisition → Data Cleaning → Validation → Exploration → Analysis → Modeling → Visualization → Communication**

This repository is intentionally more than a collection of completed course exercises.

Throughout the program, I frequently extended the original labs and assignments with
my own:

- Exploratory analysis
- Additional validation steps
- Explanations of analytical concepts
- Interpretation of results
- Alternative approaches
- Code improvements
- Additional visualizations
- Analytical observations
- Conclusions and recommendations

The objective was not simply to make the code work.

The objective was to understand:

> **What does the result mean?  
> Can it be trusted?  
> What else can be learned from the data?**

# Portfolio Focus

The projects in this repository demonstrate practical experience with:

- SQL and relational databases
- Python for data analysis
- Data cleaning and transformation
- Exploratory Data Analysis (EDA)
- Statistical analysis
- Regression modeling
- Model evaluation
- Data visualization
- Geospatial analysis
- Interactive dashboards
- APIs and web scraping
- Business-oriented KPI analysis
- Generative AI applied to analytics
- Analytical documentation and communication

A recurring principle throughout the repository is:

> **Do not stop when the expected output is obtained.  
> Validate it, interpret it, and explore what else the data can reveal.**
